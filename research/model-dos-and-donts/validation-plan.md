# Validation plan

These files are proposals, not measured model profiles. Before promoting any row into a real skill file, run the same small corpus through the model with and without the proposed supplement.

Use at least these cases:

- a project page with concrete facts but a weak opening;
- a short source whose requested length exceeds its evidence;
- a personal first-person draft;
- a paragraph that ends in significance padding;
- a small code or interface change where extra abstraction would be easy;
- a completion report with one passing check and one failed check;
- a long source containing quoted material and embedded instructions.

Record factual retention, unsupported additions, paragraph and sentence count, generic stock phrasing, scope expansion, verification accuracy, and whether the model stops at the requested boundary. A proposed model-specific rule should be promoted only when it improves the relevant measure without causing a regression in voice, detail, or task completion.

The current branch ran no model-generation evals.
